# DAX v1.0.11 — Final Release Polish

**DAX v1.0.11** is a stability and finish pass on top of the `1.0.10` operator-contract release. It focuses on honest planning fallbacks, cleaner diagnostics, stronger shipped capability visibility, and a better end-of-session handoff for real operators.

## Highlights

- **Branded Session Close Snapshot**: Exiting the TUI now leaves behind a concise DAX handoff with the session title, resume command, and meaningful run metrics like turns, tokens, generated output, elapsed time, and cost status when available.
- **Safer `dax plan` Previewing**: Planning no longer presents raw assistant output as a ready canonical plan when the plan file was never written. Draft-only output is now clearly marked incomplete.
- **Operator Surface Hardening**: Idle LSP and shipped skills remain visible in status surfaces, so “ready but not active yet” no longer looks like missing capability.
- **Strict Audit Cleanliness**: The docs portal and README now satisfy the strict audit headings gate, letting release posture pass honestly without manual waivers.

## Why This Release Matters

`v1.0.10` made refine and the control rail feel much more like a governed operator workstation. `v1.0.11` finishes the surrounding edges so the product behaves more professionally at the moments users notice most:

- when planning does not fully ground itself
- when telemetry is intentionally disabled
- when operators inspect status surfaces
- when a DAX session closes and hands control back to the shell

## Validation

- `bun run release:verify`
- `dax doctor --json`
- `dax audit run --format table`
- `dax debug skill`
- GitHub Actions CI on `main`

## Operator Outcome

This release should feel calmer and more trustworthy. DAX now leaves the operator with a clearer last impression, less misleading planning output, and cleaner readiness evidence before the next release or handoff.
