# DAX v1.0.3 — Google Auth Clarity & TUI Polish

**DAX (Deterministic AI Execution)** v1.0.3 tightens the public release experience with clearer Google authentication choices, better Gemini subscription support, and a more polished terminal UI.

---

## What's New

### Clearer Google Auth Choices

The auth flow now presents the clearest lane for the operator's current setup instead of always showing every possible Google path.

For most users, DAX shows these three visible options:

| Option                         | Best For                                         |
| ------------------------------ | ------------------------------------------------ |
| **Gemini API Key**             | Free tier and pay-as-you-go usage                |
| **Gemini Subscription Sign-In**| Gemini Pro and Pro Plus users                    |
| **Your Google OAuth App**      | Teams using their own OAuth client credentials   |

`Gemini Subscription Sign-In` uses your local `gemini` CLI session when available. When `DAX_GOOGLE_CLI_CLIENT_ID` and `DAX_GOOGLE_CLI_CLIENT_SECRET` are configured, DAX can also use direct browser sign-in for the same subscription lane.

### Better Gemini Subscription Support

- Improved routing for Code Assist API usage
- Better handling for Gemini Pro and Pro/Plus auth paths
- Cleaner UX around quota project support
- Expired Gemini CLI imports now tell operators to run `gemini` again instead of sending them to custom OAuth setup

### TUI Polish

- Animated DAX header treatment
- Braille activity spinner while streaming
- Refined borders, dialogs, and autocomplete positioning

---

## Changed

- Google OAuth client credentials are now expected through:
  - `DAX_GOOGLE_CLI_CLIENT_ID`
  - `DAX_GOOGLE_CLI_CLIENT_SECRET`
- Terminal visuals received another polish pass for day-to-day usability

---

## Fixed

- Improved retry behavior for rate-limit responses
- Correct forwarding for `x-goog-user-project`
- Better handling for Gemini OAuth scope modes, including `full` and `compat`

---

## Breaking Changes

None intended for normal user workflows.
