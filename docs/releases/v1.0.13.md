# DAX v1.0.13

`v1.0.13` is a safety and stability release focused on runtime guard hardening and session protection.

## Highlights

- **Boundary Hardening for Vague Runs**
  - Runtime guard now blocks mutating actions when intent is vague and no concrete scoped contract targets are present.
  - This prevents accidental mutations on under-specified tasks.

- **Primary Loop Safety Rails**
  - Session loop now enforces a hard primary step budget to prevent indefinite drift on under-specified tasks.
  - Operators are protected from runaway sessions on ambiguous prompts.

## Fixed

- **Codex Boundary Drift Path**: A vague prompt path that previously escalated into `apply_patch` under weak constraints is now stopped by trust guards.
- **Provider Stall Recovery**: Session processor now enforces deterministic stream stall timeout behavior so long-running provider silence does not hang runs indefinitely.

## Operator Impact

This release improves safety boundaries for vague or under-specified runs. The primary loop budget ensures operators don't lose control of long-running sessions, while the provider stall timeout prevents hangs from silent providers.
