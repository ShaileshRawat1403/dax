# DAX v0.1.1 — Auth UX & UI Polish

**DAX (Deterministic AI Execution)** v0.1.1 focuses on improving provider authentication UX and polishing the terminal interface.

---

## What's New

### Improved Google Auth

Three clear authentication options for Google/Gemini:

| Option                     | Best For                                           |
| -------------------------- | -------------------------------------------------- |
| **Gemini API Key**         | Free tier and pay-as-you-go                        |
| **Import from Gemini CLI** | Pro/Plus subscribers (import existing credentials) |
| **Sign in with Google**    | Direct OAuth sign-in with your own credentials     |

Each option now includes helpful descriptions in the TUI auth dialog.

### UI Polish

- **Header animation**: "DAX" letters with color cycling (primary → accent → secondary)
- **Activity indicator**: Braille spinner appears on bottom-left when streaming
- **Prompt border**: Added top border for visual clarity
- **Autocomplete**: Improved dropdown positioning and styling
