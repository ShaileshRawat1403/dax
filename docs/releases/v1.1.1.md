# DAX v1.1.1

`v1.1.1` is a release-hardening patch focused on session reliability, operator trust, and controlled retirement of dead legacy UI paths.

## Highlights

- **Session Review Reliability**
  - Fixed question routing so live operator questions still appear when projected run data is incomplete.
  - Free-form answers in the review pane now submit correctly instead of getting stranded behind option-only behavior.
- **Operator Controls That Actually Act**
  - Session operator controls now trigger real actions such as export, fork, and help instead of living as decorative state.
  - Prompt-side operator context is now injected into execution context rather than remaining UI-only.
- **Todo Visibility in the Live Stream**
  - The active plan/todo list now appears as a first-class stream surface when relevant.
  - Completed steps remain visible as finished progress instead of being hidden behind a planning-only gate.
- **Legacy Cleanup Without Authority Drift**
  - Removed dead legacy session sidebar/question UI paths.
  - Kept active runtime compatibility paths, but fenced them with explicit warnings, tracking, and tests.

## Validation

- **Typecheck passed**: `bun run --cwd packages/dax typecheck`
- **Focused TUI and session regression coverage passed**:
  - question and run-gateway hardening
  - transcript table formatting
  - session stream and display model checks
  - legacy tool compatibility conversion
- **Release verification passed**: `bun run release:check`

## Operator impact

This patch makes DAX feel more trustworthy in the exact places where reliability matters most during a live session: approvals/questions, operator controls, progress visibility, and transcript/export surfaces. It also reduces repo drift by removing dead UI paths and centralizing the deprecated compatibility behavior that still needs to ship.
