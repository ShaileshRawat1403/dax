# DAX v1.0.5 — Gemini Subscription UX Hardening

This patch release improves the Gemini Pro/Plus subscription path and smooths out rate-limit behavior without changing the product model.

## Highlights

- Reduced unnecessary Gemini subscription traffic by skipping decorative title-generation calls on the subscription lane.
- Persisted Gemini subscription cooldowns across separate DAX runs so a fresh process does not immediately hammer the same hot lane again.
- Kept the existing plain-language retry copy for subscription throttles while making the lane itself less wasteful.
- Included the release asset packaging hardening that landed after `v1.0.4`.

## Why this release matters

`v1.0.4` worked, but it could still spend subscription capacity on background niceties instead of the user’s actual request. `v1.0.5` makes the Gemini subscription path leaner and more predictable.

## Validation

- Focused Gemini subscription tests passed.
- Typecheck passed.
- Live subscription-backed dummy run succeeded with:
  - model: `google/gemini-2.5-flash`
  - output: `GEMINI_STREAM_OK`

## Notes

Google’s own short-window subscription throttles can still happen. This release reduces DAX’s contribution to that problem; it does not remove provider-side burst limits.
