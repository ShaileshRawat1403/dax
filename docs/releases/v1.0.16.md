# DAX v1.0.16

`v1.0.16` is a UX stabilization release focused on workstation posture continuity and interaction robustness.

## Highlights

- **Unified Workflow Posture**
  - Workflow Mode is now a global workstation preference rather than session-local state.
  - This ensures a consistent operating posture (Plan, Build, Explore, etc.) as the operator moves between Home and Session views.
- **Synchronized Agent State**
  - Added a global synchronization effect that keeps the workstation's workflow mode in lockstep with the active agent.
  - Switching agents (via command palette or shortcuts) now automatically updates the global workflow posture.
- **Robust Tab Cycling**
  - Resolved a regression where the Tab key would stop toggling agents once a session started.
  - Improved cycling logic to correctly identify the next agent even when a specialized or non-primary agent is currently active.
- **Reactive Mode Labels**
  - Fixed non-reactive indicator labels in the prompt box.
  - The current workflow mode label now updates instantly upon switching, providing immediate visual feedback.

## Validation

- **Typecheck passed**: Verified structural integrity of the TUI reactivity changes.
- **Mode Ring Sanity**: Confirmed robust cycling through Plan -> Build -> Explore -> Docs -> Audit loop.
- **Continuity Test**: Verified that selecting a mode in one session correctly persists when returning Home or starting a new session.
- **Execution Test**: Confirmed that posture-switched agents correctly receive and process intents at execution time.

## Operator impact

This release eliminates several persistent friction points in the TUI interaction model. By treating the workflow mode as a global workstation preference, DAX now maintains a steady operating posture across different views, making the transition between sessions and the home screen feel more seamless and predictable.
