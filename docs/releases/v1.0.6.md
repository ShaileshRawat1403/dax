# DAX v1.0.6 — TUI Stream and Control Pane Polish

This patch release improves the core terminal workstation experience without changing DAX's product model.

## Highlights

- Restored a fuller, more natural left-side execution stream inside the newer response container style.
- Kept repetitive discovery chatter out of the main stream while bringing meaningful review and execution activity back into the left pane.
- Made the right-side plan pane follow live context more closely, with better focus labels and calmer observability wording.
- Tightened the plan-pane copy so the narrative stream stays primary and the right pane stays useful without competing with it.

## Why this release matters

`v1.0.5` improved the Gemini subscription path, but the TUI still felt uneven during real use. `v1.0.6` makes the workstation feel more coherent: the left side carries the work, and the right side reacts to it more intelligently.

## Notes

This release is primarily a UX and presentation hardening pass. It does not change the DAX workflow model, release model, or provider integration contract.
