# DAX v1.0.15

`v1.0.15` is a stabilization patch focused on session UX correctness and operator clarity.

## Highlights

- Quiet mode is now strict and predictable.
  - Non-critical right-pane chrome is hidden in quiet mode.
  - Hard intervention checkpoints remain visible when required.
- Memory pane is now functional.
  - `note`, `list`, and `rules` tabs render live PM-backed data.
  - Reflection memory, PM notes, and PM rules are surfaced as operator context.
- Stream and right-pane coupling is smoother.
  - Left stream auto-follow remains stable during live output.
  - Right pane tracks stage transitions without disappearing/flickering.
- Persona and ELI12 boundaries are preserved.
  - Personas remain presentation-only.
  - ELI12 remains explanation-only and does not alter governance or permissions.
- Documentation aligned to shipped behavior.
  - TUI design freeze, mode model, and user guide now reflect actual runtime behavior.

## Validation

- Typecheck passed.
- Session display and surface presentation tests passed.
- Manual dummy sessions confirmed:
  - concise lightweight response flow
  - plan/explore flow with live operator traces
  - approval/blocked visibility and next-step clarity

## Operator impact

This release should feel calmer and more trustworthy in day-to-day use: less UI drift, stronger memory continuity, and clearer separation between presentation controls and execution governance.
