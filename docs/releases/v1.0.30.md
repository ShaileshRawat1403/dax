# DAX v1.0.30

`v1.0.30` is a performance and stability release for the Gemini provider, specifically optimizing the subscription lane for smoother operator experience during high-volume work.

## Highlights

- **Gemini Subscription Lane Optimization**
  - **Aggressive Slot Management**: The Gemini scheduler now releases its concurrency slot during backoff or global cooldown periods. This prevents the entire request queue from stalling when one or more requests are waiting on provider-side rate limits.
  - **Tuned Concurrency**: Reduced the default subscription lane concurrency to `2` to better align with typical Code Assist API limits, leading to fewer `429 Too Many Requests` errors.
  - **Jittered Backoff**: Introduced randomized jitter to exponential backoff delays to prevent "thundering herd" bursts after a cooldown expires.
- **Enhanced Stream Robustness**
  - **Faster Chunk Timeouts**: Reduced the idle stream timeout to 5 seconds. This allows DAX to detect and recover from hung provider connections twice as fast, improving TUI responsiveness.
- **Improved Cooldown Persistence**
  - Cooldown periods are now checked before a request consumes a concurrency slot, ensuring that persisted rate-limit signals from other sessions are respected immediately.

## Validation

- **Live Throttling Test**: Verified that the scheduler correctly pauses and resumes under real `429` pressure from `gemini-2.5-pro`.
- **Concurrency Verification**: Confirmed that slots are correctly released during `Bun.sleep` periods.
- **Regression Suite**: All 651 core tests passed across session, governance, and presentation layers.
- **Typecheck passed**: Verified no regressions in plugin or scheduler interfaces.

## Operator Impact

Operators using the Gemini subscription lane (via CLI import or Code Assist sign-in) will experience significantly less "lag" during complex tasks. When the provider throttles, DAX now stays responsive, manages the retry queue more efficiently in the background, and provides clearer feedback through the workstation pane without blocking the entire session.
