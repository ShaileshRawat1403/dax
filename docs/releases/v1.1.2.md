# DAX v1.1.2

`v1.1.2` is a security and stability patch focused on dependency hardening, approval-flow correctness, and the new dax-ui interaction contract. It also lands the Rust ledger and structural indexer sidecars, the verification harness, and a runtime-guard model where policy violations pause-and-await instead of fail-fast.

## Highlights

- **Vulnerability sweep**: 87 → 1 known advisories. Critical `protobufjs` ACE patched. High-severity Hono auth-bypass, MCP SDK cross-client leak, Axios prototype-pollution chain, Seroval RCE, and OpenTelemetry Prometheus crash all resolved.
- **Approval flow correctness**: `deny` actually denies, `Permission.reply` accepts canonical `apr_*` IDs, pending-approval source of truth unified across every UI surface, and the store is hardened against TOCTOU and idempotency bugs.
- **Runtime guard becomes a pause point**: policy violations now pause execution and await operator approval rather than failing fast. Pending approval expires cleanly on timeout and the listener is unsubscribed.
- **dax-ui interaction contract**: header, footer, inspector, and operator-mode pane consume a single environment projection driven by a state resolver. Inspector auto-opens on attention states instead of ad-hoc triggers.
- **Rust sidecars expanded**: `dax-ledger` (canonical event log) and `dax-indexer` (structural relevance) land alongside the existing `dax-core`, `dax-policy`, and `dax-audit` crates. Indexer output now drives intent planning.
- **Verification harness**: `dax verify` produces a proof bundle covering replay, policy, and audit determinism. Smoke eval ladder is now part of `release-verify`.
- **Governance widened**: `.env` and credentials are gated across every discovery and content tool, not just edit paths.
- **Developer experience — skill roster doubled**: 12 new audit/review skills land alongside a shared output contract and three-layer branch-hygiene enforcement (committed AGENTS.md/CLAUDE.md rules, portable git pre-commit hook, optional per-user Claude Code PreToolUse hook). See the Developer Experience section in the CHANGELOG for the full list.

## Operator impact

This patch is the most security-loaded release since 1.0.0. Any team running DAX with telemetry exporters, MCP servers, or the Infisical SDK should plan to upgrade — the protobufjs and MCP SDK CVEs are runtime-reachable. The approval-flow rewrite eliminates the class of bug where a denied request could still proceed, which materially raises the trust posture of the RAO loop. The pause-and-await guard means long-running sessions stop at the policy boundary instead of aborting, which is the behavior governance reviewers actually want.

## Known Limitations

- One moderate `file-type` advisory remains via the TUI library; unblocking requires a major `@opentui/core` bump (0.1.x → 0.2.x) deferred to 1.2.0.
- Tree-sitter HTML injections are not active and Nix syntax uses a community WASM build.
