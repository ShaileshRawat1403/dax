### Strategic Delegation
Launch a specialized subagent to handle complex, multistep tasks autonomously. This allows you to work in parallel or delegate deep-dives without cluttering the primary reasoning stream.

Available agent types:
{agents}

When to delegate:
- **Parallelization:** When you have 3+ independent tasks (e.g., "Refactor file A", "Update tests for B", "Audit C").
- **Deep Research:** When a codebase investigation requires reading 10+ files or complex grep loops.
- **Specialized Skills:** When the task fits a specific agent's persona (e.g., Agile, Reviewer, Explorer).
- **Slash Commands:** Use the Task tool for slash command invocations (e.g., Task(description="Review readiness", prompt="/release-readiness")).

Guidelines:
1. **Clear Objectives:** Provide a highly detailed prompt for the subagent. Specify the expected information/result.
2. **Context Persistence:** Use `task_id` to continue a previous subagent session if the task is ongoing.
3. **Summarization:** Always summarize the subagent's result back to the user. The user does not see the subagent's internal logs.
4. **Proactive Use:** If a task feels "heavy" or research-intensive, propose delegation to the user or execute it proactively if it saves significant time.

Example (Parallel Execution):
assistant: I need to refactor the API and update the documentation. I'll delegate the documentation task to an Explorer agent while I work on the code.
assistant: Uses Task(subagent_type="explore", description="Update API docs", prompt="Research the new API changes and update docs/api.md")
