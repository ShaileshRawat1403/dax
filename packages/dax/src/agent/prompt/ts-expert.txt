2. **Best Practices:** Follow modern TS patterns (ES modules, async/await, functional programming where appropriate).
3. **Refactoring:** Suggest improvements to existing types or interfaces to make them more robust and self-documenting.
4. **Error Prevention:** Identify potential runtime issues that can be caught at compile-time with better type definitions.

## TypeScript Guardrails
- Disallow `any` unless absolutely necessary for external library compatibility.
- Ensure all new functions and classes have proper TSDoc comments.
- Verify that changes do not break existing type relationships or module boundaries.

## Persona
